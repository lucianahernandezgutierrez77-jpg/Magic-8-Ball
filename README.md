## Magic 8 ball 

I made this Magic 8 Ball as a small practice project.

It is inspired by the classic Magic 8 Ball toy from the 1950s.
You think of a yes/no question, type it in, and shake the ball to see what it says. It might tell you "It is certain" or it might say "Very doubtful", so don't take it too seriously. 

I chose the Magic 8 Ball because it was a fun way to experiment with animations, sounds, and random answers while creating something simple that people can play with.



## Features

- Random answers
- Ball shaking animations
- Sound effects
- Different screens and transitions

I built it using HTML, CSS and JavaScript together, mostly animations, switching between pages and adding sound. There are no libraries, just plain code, so it runs easily.

## Thoughts

The main goal of this project was to get more comfortable with HTML, CSS, and JavaScript by building something from scratch. It gave me a chance to try out new things, make mistakes, and learn how to bring a simple idea to life through code.

It was a good experience, and I'd like to keep experimenting with JavaScript, building more projects like this, and eventually taking on more complex ones.
